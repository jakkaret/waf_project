ตั้งค่า Main Server — Control Plane

Main Server คือศูนย์กลางควบคุมระบบทั้งหมด รัน Dashboard, WAF Engine, ClickHouse Analytics, Redis, และ Control API

ℹ️

ขั้นตอนทั้งหมดในหน้านี้ SSH เข้า Main Server (178.104.53.123) ก่อน: ssh root@178.104.53.123

ขั้นตอนการตั้งค่า Main Server

สร้างไฟล์ .env
กำหนดค่า Secret และ Config ทั้งหมด
🧠 Main Server
▶
🤔 ทำไม? ค่า Secret เช่น Password, API Key, Secret Token ไม่ควรฝังในโค้ด ต้องเก็บใน .env ซึ่งไม่ถูก commit ขึ้น Git
Main Server — สร้าง .env 🧠 Main Server 
# สร้าง CONTROL_TOKEN ปลอดภัย
CONTROL_TOKEN=$(openssl rand -hex 32)
echo "CONTROL_TOKEN=$CONTROL_TOKEN"

# สร้างไฟล์ .env
cat > /root/waf_project/.env << EOF
PROJECT_NAME="WAF CDN Platform"
ENVIRONMENT="production"

JWT_SECRET_KEY="$(openssl rand -hex 32)"
JWT_EXPIRE_MINUTES="1440"

CLICKHOUSE_HOST="clickhouse"
CLICKHOUSE_PORT="8123"
CLICKHOUSE_USER="default"
CLICKHOUSE_PASSWORD="$(openssl rand -hex 16)"

REDIS_HOST="redis"
REDIS_PORT="6379"

CONTROL_TOKEN="$CONTROL_TOKEN"

TELEGRAM_BOT_TOKEN="ใส่ Bot Token จาก @BotFather"
TELEGRAM_CHAT_ID="ใส่ Chat ID ของคุณ"

PUBLIC_SERVER_IP=178.104.53.123
EOF

cat /root/waf_project/.env
3
รัน Docker Compose Stack
Build และ Start ทุก Service
🧠 Main Server
▶
🤔 ทำไม Docker Compose? เราใช้ Docker Compose เพื่อจัดการ Container หลายตัวพร้อมกัน กำหนด Network ระหว่าง Container และ Volume ในการเก็บข้อมูล ทำให้ Start/Stop/Update ทั้งระบบได้ด้วยคำสั่งเดียว
Main Server — Start Docker Compose 🧠 Main Server 
# เข้าไปใน directory
cd /root/waf_project

# Build Image ทั้งหมดและ Start (ครั้งแรกอาจใช้เวลา 3-10 นาที)
docker compose up -d --build

# ตรวจสอบสถานะ Container ทุกตัว
docker compose ps

# ดู Log แบบ Real-time (กด Ctrl+C เพื่อออก)
docker compose logs -f --tail=50
✅

ทุก Container ควรมีสถานะ Up ถ้าตัวไหน Exit หรือ Restarting ให้รัน docker logs <container-name> ดู error

4
ตั้งค่า Systemd Service สำหรับ FastAPI
ให้ FastAPI Backend รัน Auto-start
🧠 Main Server
▶
🤔 ทำไมต้อง Systemd? FastAPI Dashboard รันนอก Docker (รันตรงบน Host) เพราะต้องสั่ง docker exec ไปที่ Container WAF Systemd จะทำให้มัน Start อัตโนมัติเมื่อ Server รีบูต และ Restart ถ้า crash
Main Server — สร้าง Systemd Service 🧠 Main Server 
# สร้างไฟล์ service
cat > /etc/systemd/system/waf-dashboard.service << 'EOF'
[Unit]
Description=WAF Dashboard FastAPI Service
After=network.target docker.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/waf_project/dashboard/backend
ExecStart=/root/waf_project/dashboard/backend/.venv/bin/python main.py
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
EOF

# เปิดใช้งานและ Start
systemctl daemon-reload
systemctl enable --now waf-dashboard.service

# ตรวจสอบสถานะ
systemctl status waf-dashboard.service
✅

เห็น Active: active (running) = สำเร็จ

🤔 ทำไมต้อง Build? React App ต้องถูก Compile (transpile + bundle) ก่อนจึงจะรันในเว็บ Browser ได้ FastAPI จะ serve ไฟล์ที่ Build แล้วใน /dashboard/frontend/dist/

npm install

ls -la dist/
