📖 Reference

API Reference — รายการ API และ Environment Variables

รายการ API Endpoints ทั้งหมด Environment Variables ที่สำคัญ และวิธีใช้งาน

🔐 Authentication

ทุก API ต้องส่ง JWT Token ใน Header:

Authorization Header 
Authorization: Bearer <your-jwt-token>

รับ Token ได้จาก:

Login API 
curl -X POST http://178.104.53.123:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"yourpassword"}'

📡 API Endpoints

MethodEndpointคำอธิบาย
POST/api/auth/loginLogin รับ JWT Token
POST/api/auth/registerสมัครบัญชีใหม่
GET/api/originsดู Origin ทั้งหมดของ User
POST/api/originsเพิ่ม Origin ใหม่
GET/api/rules/ดู WAF Rules ทั้งหมด
POST/api/rules/สร้าง WAF Rule ใหม่ (Admin)
POST/api/rules/syncSync Rules ไปยัง Edge Nodes
GET/api/analytics/statsสถิติทราฟฟิกจาก ClickHouse
GET/api/cdn/nodesสถานะ Edge Nodes ทุกตัว
POST/api/cdn/logs/ingestรับ Log จาก Edge Node (internal)
GET/api/domains/ดู Domain ทั้งหมดของ User

🔑 Environment Variables สำคัญ

Variableเครื่องคำอธิบาย
JWT_SECRET_KEYMainSecret ใช้ Sign JWT Token ต้องยาวและสุ่ม
CONTROL_TOKENMain + EdgeToken สำหรับยืนยันตัวตนกับ Control API ต้องตรงกันทั้งสองเครื่อง
CLICKHOUSE_PASSWORDMainPassword สำหรับ ClickHouse Database
TELEGRAM_BOT_TOKENMainToken ของ Telegram Bot จาก @BotFather
TELEGRAM_CHAT_IDMainChat ID ที่ Bot จะส่งการแจ้งเตือนไป
EDGE_REGIONEdgeระบุภูมิภาคของ Edge Node เช่น TH, SG, JP
MAIN_SERVER_IPEdgeIP ของ Main Server ที่ Edge จะชี้ Upstream ไป
CONTROL_API_URLEdgeURL ของ Control API ที่ Edge จะดึง Rule Bundle
